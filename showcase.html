🔌 Seeed Studio XIAO ESP32C6 Pin Connections Fast-Mode 400kHz I2C

⚡ Power Rails

3V3 (Pin 12) → MPU-6050 VCC & SSD1306 VCC
GND (Pin 13) → Common Ground (MPU & OLED)
VBUS / 5V → USB-C 5V Input

🔄 Shared I2C Bus (`i2c0`)

D4 (GPIO 22) → SDA (Shared Data Line)
D5 (GPIO 23) → SCL (Shared Clock Line)
Pull-Ups Internal SoC Pull-Ups Enabled

📍 Hardware I2C Addresses

0x3C 0.96" SSD1306 OLED (128x64)
0x68 MPU-6050 6-Axis IMU (AD0=GND)
GPIO 15 Onboard Yellow LED (Active-LOW)

🚀 Terminal Commands Quick-Reference 
# 1. Activate Zephyr Environment
. .\scripts\env.ps1

# 2. Build with Sysbuild (MCUboot + Application)
west build -p always -b xiao_esp32c6/esp32c6/hpcore --sysbuild .\levelindicator

# 3. Flash to board on COM18
.\scripts\flash.ps1 -Port COM18

# 4. Open Serial Monitor (115200 baud)
.\scripts\monitor.ps1 -Port COM18
